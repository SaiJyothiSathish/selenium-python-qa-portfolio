# Selenium Python QA Automation Portfolio

A QA automation testing project for the Sauce Demo e-commerce practice application.

## Skills Demonstrated

- Manual testing and test-case design
- Selenium WebDriver with Python
- pytest framework
- Page Object Model (POM)
- Explicit waits and locators
- Positive and negative test scenarios
- HTML test reporting
- SQL validation queries
- Bug-report documentation

## Automated Test Scenarios

1. Valid user login
2. Invalid user login
3. Add Sauce Labs Backpack to the cart
4. Complete the checkout process

## Technologies Used

- Python
- Selenium
- pytest
- pytest-html
- Chrome
- SQL
- PyCharm
